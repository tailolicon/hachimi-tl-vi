# Source attribution and provenance

The Vietnamese translation pipeline is independent from UmaTL's English translation corpus and does not use UmaTL English text as generative-AI input.

## Current bootstrap translation source

For a recent, Hachimi-compatible JP-server corpus, source checkpoints are normalized from:

- Project: **Hachimi-Hachimi/tl-zh-cn**
- Language: Simplified Chinese (`zh-CN`)
- Upstream branch: `dev`
- Game region: Japanese server
- License stated by upstream: **CC BY-NC-SA 4.0** for the translation material described in its README, including translation work continued from Trainers' Legend G (TLG).
- Upstream project: https://github.com/Hachimi-Hachimi/tl-zh-cn

Every normalized source record stores the exact upstream commit SHA, source path, JSON path and source-text fingerprint. This allows later source upgrades to retranslate only changed material.

The upstream repository also contains or describes data originating from *Umamusume: Pretty Derby*. Copyright in the original game and its data remains with the respective rights holders. This repository claims no ownership of the original game data.

## Auxiliary character-identity context

`glossary/characters.json` is generated from compact identity metadata, not from an English translation corpus. The generator joins:

- the exact pinned zh-CN `text_data` category 6 from the translation source above, and
- structured character identity data currently generated by `BrandonL00/UmaSim` from `umapyoi.net` character information.

Only factual/structural fields needed for entity resolution are retained: numeric game ID when known, canonical Latin name, Japanese name, zh-CN alias, internal/preferred identifier and official character link. Long profile/slogan/personality prose from auxiliary sources is intentionally not copied into the registry or AI prompt.

Very new records without a reliable game ID are represented using a stable slug key rather than guessing an ID. A static ID override is permitted only when independently cross-checked. The current Titleholder override (`1148`) is supported by the pinned source mapping `1148 -> 领衔` and the Hong Kong Jockey Club's horse-name mapping `TITLEHOLDER / タイトルホルダー -> 領銜`. Samson Big remains a no-game-ID structured identity until a reliable mapping is available.

Manual Vietnamese speech/relationship notes are maintained separately inside the generated record and survive regeneration; they are project-curated context rather than copied third-party profile prose.

## Generated terminology candidates

`glossary/generated_candidates.json` is derived from the exact pinned zh-CN source snapshot. It is discovery metadata only. Candidate skill, race, support-card, character and scenario strings do **not** become canonical Vietnamese terms until reviewed and promoted into `glossary/term_registry.json`.

## Translation policy

The current bootstrap flow is:

`recent zh-CN JP-server corpus -> Vietnamese draft -> language/style review -> terminology review -> structural QA -> Hachimi output`

When a sufficiently recent direct Japanese corpus becomes available, Japanese is preferred and the same stable locators/fingerprints are used to migrate entries incrementally.

Generated Vietnamese material derived from CC BY-NC-SA source material must retain the applicable attribution, non-commercial and share-alike obligations. This file is provenance documentation, not legal advice.
